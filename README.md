# ⚡ Neon Dashboard

An interactive and visually appealing dashboard built with **Python, Streamlit, Pandas, and Plotly**.

This project demonstrates how to create a modern analytics dashboard with a neon-themed user interface, animated gradient background, glassmorphism KPI cards, interactive filters, and dynamic data visualizations.

## Features

- 🎨 Animated gradient background
- 💡 Neon glowing KPI cards
- 👥 Employee selection using sidebar filters
- 📊 Interactive employee age analysis
- 📈 Animated Plotly charts
- 🧊 Glassmorphism-inspired UI design
- 📋 Employee data analysis using Pandas

## Technologies Used

- Python
- Streamlit
- Pandas
- Plotly
- HTML
- CSS

## Installation

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```

## Project Purpose

The goal of this project is to explore interactive dashboard development using Streamlit while combining data analytics, visualization, and custom CSS styling to create an engaging user experience.
